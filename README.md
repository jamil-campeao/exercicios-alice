Como colocar o projeto na sua máquina:

- Clone o repositório: git clone https://github.com/jamil-campeao/exercicios-alice.git
- Entre no vscode na pasta do projeto
- crie a venv. Ex windows: python -m venv venv
- antes de instalar as dependencias, entre na venv: venv\Scripts\activate.bat
- depois execute o comando: pip install -r requirements.txt
- Após isso execute python app.py para iniciar a API
